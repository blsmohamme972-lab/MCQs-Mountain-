# Scientific references and simplifications

The medical content is deliberately foundational and qualitative. References support the explanatory concepts, not the quantitative fidelity of these drawings. Original SVG geometry was authored for this library; no diagrams, photographs, audio or font files were copied from these sources. This is not a medical-device or clinical-validation claim.

| Template | Reference | Important boundary |
| --- | --- | --- |
| Vessel flow | [NHLBI: Atherosclerosis](https://www.nhlbi.nih.gov/health/atherosclerosis) | Lumen geometry only; no hemodynamic calculation. |
| Alveolar exchange | [NHLBI: The respiratory system](https://www.nhlbi.nih.gov/health/lungs/respiratory-system) | O2 air-to-blood; CO2 blood-to-air. Ten enlarged air spaces, capillary mesh and barrier thickness are illustrative. |
| Cardiac circulation | [NHLBI: How blood flows through the heart](https://www.nhlbi.nih.gov/health/heart/blood-flow) | Correct compartment order; schematic placement, valves omitted, blue is only a convention. |
| ECG | [OpenStax A&P 2e 19.2](https://openstax.org/books/anatomy-and-physiology-2e/pages/19-2-cardiac-muscle-and-electrical-activity) | Electrical sequence only; no calibrated lead, diagnostic inference or paper speed. |
| Saltatory conduction | [OpenStax A&P 12.4](https://openstax.org/books/anatomy-and-physiology/pages/12-4-the-action-potential) | Nodal regeneration highlighted; internodal currents and velocity omitted. |
| Chemical synapse | [OpenStax A&P 2e 12.5](https://openstax.org/books/anatomy-and-physiology-2e/pages/12-5-communication-between-neurons) | Generic transmitter/receptor; calcium entry, clearance and receptor-specific effects omitted. |
| Nephron exchange | [NIDDK: Your kidneys and how they work](https://www.niddk.nih.gov/health-information/kidney-disease/kidneys-how-they-work); [OpenStax A&P 2e 25.5](https://openstax.org/books/anatomy-and-physiology-2e/pages/25-5-physiology-of-urine-formation) | Functional directions; not a complete nephron or selective molecular model. |
| Membrane transport | [OpenStax: Passive transport](https://openstax.org/books/concepts-biology/pages/3-5-passive-transport); [Active transport](https://openstax.org/books/concepts-biology/pages/3-6-active-transport) | Assumes an uncharged solute; active mode is primary ATP-coupled transport, not secondary transport. |
| Leukocyte recruitment | [OpenStax A&P 2e 21.2](https://openstax.org/books/anatomy-and-physiology-2e/pages/21-2-barrier-defenses-and-the-innate-immune-response) | Qualitative recruitment sequence; adhesion molecules and mediator kinetics omitted. |
| Wound healing | [StatPearls: Wound Healing Phases](https://www.ncbi.nlm.nih.gov/books/NBK470443/) | Phases overlap; the visual timeline is not a clinical timetable. |

## Browser implementation references

[MDN requestAnimationFrame](https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame) and [MDN prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion) informed clock and motion-preference handling. They are documentation links only; the runtime does not fetch them.

Review scientific content again before repurposing a template for pathology, interventions or formal clinical instruction. Source availability and web addresses can change. Automated rendering tests do not establish scientific correctness or human usability on every device.
